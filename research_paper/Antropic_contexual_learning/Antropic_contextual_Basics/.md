Rule 1: lora_alpha = 2 × r
─────────────────────────────────────────────
r=8   → alpha=16
r=16  → alpha=32
r=32  → alpha=64
r=64  → alpha=128

Breaking this rule:
alpha too high relative to r → LoRA overpowers base model
                               model forgets original knowledge
                               training becomes unstable

alpha too low relative to r  → LoRA signal too weak
                               adapter learns nothing useful
                               same as not fine-tuning


Rule 2: more target_modules → lower learning rate
─────────────────────────────────────────────────
q,v only         → lr = 2e-4 is fine
q,k,v,o          → lr = 1e-4 is safer
all linear        → lr = 5e-5 to 1e-4


Rule 3: higher rank → watch eval loss more carefully
─────────────────────────────────────────────────────
Low rank (r=8):   more forgiving, hard to overfit
High rank (r=64): overfits fast on small datasets
                  eval loss will tell you early




Situation: Small dataset (under 1,000 examples)
────────────────────────────────────────────────
r              → 8 or 16    (low capacity, reduces overfit)
lora_alpha     → 16 or 32   (2x r rule)
target_modules → q, v only  (minimal, prevents overfit)
lora_dropout   → 0.05-0.1   (extra regularization)
epochs         → 3-5        (watch eval loss carefully)


Situation: Medium dataset (1,000 to 10,000 examples)
────────────────────────────────────────────────
r              → 16-32
lora_alpha     → 32-64
target_modules → q, k, v, o
lora_dropout   → 0.05
epochs         → 3


Situation: Large dataset (10,000+ examples)
────────────────────────────────────────────────
r              → 32-64
lora_alpha     → 64-128
target_modules → all linear layers
lora_dropout   → 0.0-0.05
epochs         → 1-2


Situation: Limited VRAM (consumer GPU)
────────────────────────────────────────────────
Use QLoRA instead of LoRA
r              → 16
lora_alpha     → 32
target_modules → q, v only
batch_size     → 1 or 2
grad_accum     → 8-16      (to compensate small batch)
max_seq_length → 1024      (reduce if still OOM)


Situation: Task is very different from base model
────────────────────────────────────────────────
r              → 64        (needs more capacity)
lora_alpha     → 128
target_modules → all linear
epochs         → more      (harder task needs more)


Situation: Task is similar to base model training
────────────────────────────────────────────────
r              → 8         (small nudge is enough)
lora_alpha     → 16
target_modules → q, v only
epochs         → 1-2
